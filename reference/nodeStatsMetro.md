# Create Metro Nodes

Create Metro Nodes

## Usage

``` r
nodeStatsMetro(y)
```

## Arguments

- y:

  Data Frame

## Value

A data frame with one row per metropolitan area: `airport` (city market
id), `pass_dep` (departing passengers), `pass_arr` (arriving
passengers), `pass_tr` (transfer passengers, 0 when the data has no
`trip_break` column), the metropolitan area information from
`MetroLookup` (`latitude`, `longitude` and `description`) and `freq`
(arrivals plus departures minus transfers).

OD_Metro <- OD_Sample
OD_Metro$origin <- OD_Metro$origin_mkt_id
OD_Metro$dest <- OD_Metro$dest_mkt_id

nodeStatsMetro(OD_Metro)
